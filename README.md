# NTI_labs

This repository contains NTI digital design labs implemented in Verilog/SystemVerilog, moving from basic combinational logic to integrated memory and datapath systems.

- **task1:** 1-bit full adder (`full_adder`) with a randomized testbench.
- **task2:** 8-bit combinational ALU with opcode-selected operations and zero detection, plus testbench.
- **task3:** Parameterized synchronous load register with reset and a randomized clocked testbench.
- **task4:** Parameterized RAM implementations (`memory` and `mem`) and a read/write memory testbench.
- **task5:** Serial-to-parallel (SIPO) command loading connected to an ALU through `alu_system`.
- **task6:** Top-level integrated system: RAM word fetch -> PISO serialization -> SIPO reconstruction -> ALU execution, with system testbench.
- **task7:** Placeholder task folder with README only (no HDL source in this folder yet).
- **task8:** Supporting lab/reference materials (PDF/image) without Verilog/SystemVerilog source files.
